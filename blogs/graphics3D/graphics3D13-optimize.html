Tối ưu performance

Ban đầu thì blog 12 là blog cuối của series này. Tuy nhiên sau đó thì mình có implement cơ chế portal lên trên engine này, và sau đó nữa mình có tách nó thành Hanvas Engine như trên nói. Qua 2 quá trình trên mình có thêm thắt sửa khá nhiều thứ. Nên mình viết thêm 2 blog 13 và 14 để cập nhật những gì mà mình đã làm với Hanvas Engine, để có cái base để build thêm bất cứ thứ gì lên nó cũng được. 😳

Demo cuối blog 12 cũng khá là mượt (khoảng 40 fps trên máy mình), tuy nhiên nó đang chạy trên 1 canvas 400x300 nhỏ xíu. Blog này ta sẽ tập trung optimize đó, nhưng thứ chúng ta đổi chỉ là cách viết code, cụ thể là cách chúng ta khai báo và xử lí dữ liệu, đặc biệt trong 2 vòng for pixel.

1. Viết 1 script nhỏ để đo thời gian từng bước

Thay vì cứ dựa vào FPS có sẵn của chúng ta (không thật sự biết chỗ nào chậm chỗ nào nhanh), thì ta sẽ đo từng bước bằng code, cụ thể là ta sẽ viết 1 script nho nhỏ để dán trong console, cho nó chạy để đo.

Script này sẽ làm nhiệm vụ: tắt cái vòng lặp render của trang đi, tự gọi từng giai đoạn của pipeline để đo (lấy thời điểm sau trừ thời điểm trước), chạy lại như vậy một số lần rồi lấy trung vị (median) của chúng. Ta lấy trung vị chứ không phải trung bình vì có lúc GC sẽ chạy nặng hơn vì 1 thứ gì đó trong background.

Script sẽ như sau: 
update = function () { };   // chặn vòng lặp requestAnimationFrame của trang lại

function frame() {
    let objectTris = [];
    objectTris.push(...ground.getTransformedTriangles());
    for (let light of pointLights)
        objectTris.push(...light.getTransformedTriangles());
    objectTris.push(...woodTower.getTransformedTriangles());

    // ------------------------ Tính thời gian shadow ------------------------
    const shadowStartTime = performance.now();

    dirLight.buildViewAndProjectionMatrix();
    dirLight.buildShadowMap(objectTris);

    const shadowTime = performance.now() - shadowStartTime;

    // ------------------------ Tính thời gian geometry ------------------------
    const geometryStartTime = performance.now();

    const viewMat = camera.getViewMatrix();
    let visibleTris = [];
    for (let tri of objectTris) {
        if (Vector3.dot(tri.getNormal(), Vector3.sub(tri.getCenter(), camera.pos)) < 0) {
            tri.mulMat4x4(viewMat);
            visibleTris.push(...tri.clipAgainstPlane(nearPlane));
        }
    }
    for (let tri of visibleTris) {
        tri.mulMat4x4(projectionMatrix);
        tri.perspectiveDivide();
    }

    const geometryTime = performance.now() - geometryStartTime;

    // ------------------------ Tính thời gian rasterize ----------------
    const rasterizeStartTime = performance.now();

    rasterizer.clearScreen();
    rasterizer.processTriangles(visibleTris);
    rasterizer.drawCall();

    const rasterizeTime = performance.now() - rasterizeStartTime;

    return {
        shadowTime,
        geometryTime,
        rasterizeTime
    };
}

function median(values) {
    const sortedValues = values.slice().sort((a, b) => a - b);
    const middleIndex = Math.floor(sortedValues.length / 2);

    return sortedValues[middleIndex];
}

// Làm nóng JIT (Just-in-time) trước khi đo
for (let i = 0; i < 5; i++) {
    frame();
}

const shadowTimes = [];
const geometryTimes = [];
const rasterizeTimes = [];

for (let i = 0; i < 20; i++) {
    const frameTimes = frame();

    shadowTimes.push(frameTimes.shadowTime);
    geometryTimes.push(frameTimes.geometryTime);
    rasterizeTimes.push(frameTimes.rasterizeTime);
}

const medianShadowTime = median(shadowTimes);
const medianGeometryTime = median(geometryTimes);
const medianRasterizeTime = median(rasterizeTimes);

console.log("Thời gian chạy (median của 20 frames):");
console.log(`  Shadow map : ${medianShadowTime.toFixed(2)} ms`);
console.log(`  Geometry   : ${medianGeometryTime.toFixed(2)} ms`);
console.log(`  Rasterizer : ${medianRasterizeTime.toFixed(2)} ms`);
console.log(
    `  Tổng      : ${(medianShadowTime + medianGeometryTime + medianRasterizeTime).toFixed(2)} ms`
);

2. Chuyển screen buffer và depth buffer thành mảng 1 chiều

Đây là cách chúng ta đang chứa màn hình và depth buffer từ blog 8: 
this.screenBuffer = [];
this.depthBuffer = [];

for (let i = 0; i < canvas.height; i++) {
    let screenRow = [];
    let depthRow = [];
    for (let j = 0; j < canvas.width; j++) {
        screenRow.push(new Color(255, 255, 255));
        depthRow.push(Infinity);
    }
    this.screenBuffer.push(screenRow);
    this.depthBuffer.push(depthRow);
}
Mảng 2 chiều thì dễ đọc và hiểu, nhưng nó tệ ở mấy điểm:
  • 120,000 object Color. Mỗi object trong Javascript không chỉ là 3 con số, nó còn có header, pointer tới hidden class... Và chúng nó nằm rải rác khắp nơi trong bộ nhớ.
  • Mảng của mảng nghĩa là đi 2 lần pointer. screenBuffer[y][x] = đọc mảng ngoài lấy pointer tới mảng trong, rồi mới đọc phần tử, rồi lại đi tiếp tới object Color. CPU có cache, và cache thích dữ liệu nằm liền nhau chứ không thích bị dắt đi lòng vòng như vậy.
  • Mảng không có kiểu [] thì javascript phải kiểm tra kiểu.
  • Và tệ nhất: cuối mỗi frame chúng ta copy toàn bộ 120,000 cái Color đó qua imageData bằng tay, tức là thêm một vòng lặp 120,000 lần nữa chỉ để ... copy.
Giải pháp: dùng mảng 1 chiều có type. Với depthBuffer thì là Float64Array, với screenBuffer thì là Uint8ClampedArray (cùng kiểu với imageData.data). Thậm chí, bạn có thể trỏ thẳng screenBuffer tới imageData.data, chứ không cần copy qua lại làm gì, như vậy hàm drawCall thì chỉ cần 1 dòng putImageData duy nhất. Lúc clearScreen ta chỉ cần dùng hàm fill để thay thế hết giá trị trong 2 mảng.

Tuy nhiên, có 1 vấn đề nho nhỏ ở clearScreen. Nếu ở clearScreen bạn gọi this.screenBuffer.fill(240), thì nhìn nó vẫn đúng, tuy nhiên bạn phải biết là bạn cũng set luôn channel alpha là 240 (mỗi phần tử trong screenBuffer là 1 channel màu), là cái canvas sẽ trong suốt 1 chút.

Để giải quyết vấn đề này, thay vì ta thêm lại 1 vòng for vào để set lại alpha (trở lại cách cũ). Thì ta tạo thêm một Uint32Array screenBuffer32 trỏ vào cùng 1 địa chỉ với imageData.data (dùng .buffer).
Lí do: imageData.data có kiểu dữ liệu là Uint8ClampedArray . Nghĩa là mỗi channel màu chỉ cần 8 bit/1 byte để lưu trữ, mỗi pixel thì có 4 channel màu, nên 1 pixel fit vừa 4 byte - một int 😳 Nên mỗi phần tử trong screenBuffer32 đại diện cho 1 pixel, nhờ vậy clearScreen chỉ cần ghi 120,000 lần thay vì 480,000 lần, và mình có thể tùy chỉnh alpha bằng cách truyền vào giá trị hex của 4 byte. Tuy nhiên bạn nên chú ý là máy tính đa số là little endian (bit lớn nhất ở cuối), thứ tự các channel sẽ là ABGR, nên ta clear dạng hex sẽ là 0xfff0f0f0, nghĩa là new Color(240, 240, 240, 255). 
class Rasterizer {
    constructor() {
        this.imageData = ctx.createImageData(canvas.width, canvas.height);
        this.screenBuffer = this.imageData.data;

        this.screenBuffer = this.imageData.data;    // trỏ thẳng tới imageData.data
		this.screenBuffer32 = new Uint32Array(this.imageData.data.buffer);  // cùng một vùng nhớ, nhưng nhìn 4 byte RGBA của một pixel như một số 32 bit
        this.depthBuffer = new Float64Array(canvas.width * canvas.height);

        this.clearScreen();
    }

    clearScreen() {
        this.screenBuffer32.fill(0xfff0f0f0);   // alpha, blue, green, red (little endian) = 255, 240, 240, 240
        this.depthBuffer.fill(Infinity);
    }

    ...

    drawCall() {
        ctx.putImageData(this.imageData, 0, 0);   // 1 dòng duy nhất, không copy đâu qua đâu hết
    }
}

9 cấp phát động mỗi pixel 😳 mà bạn nên nhớ tam giác sau có trùng pixel thì pixel lại chạy lại lần nữa (nếu qua được depth test), garbage collector sẽ khá vất vả. Nói thật thì như vậy nó khá dễ đọc, nhìn hiểu công thức toán học, nhìn đúng "hướng đối tượng". Tuy nhiên với 1 chỗ mà gọi nhiều như vậy, ta nên hi sinh sự dễ đọc đó để đổi lấy performance, ta sẽ thay mọi chỗ dùng Vector3, Vector2, ... thành dùng số thuần, biến const.

Ngoài ra, việc truy cập 1 property trong class cũng sẽ tốn performance tí (nó sẽ build up với mấy trăm nghìn pixel như vậy), điển hình 1 vài property: this.screenBuffer, this.depthBuffer, canvas.width, canvas.height, triWorldNormal.x|y|z, tri.vertices[0|1|2].x|y|z, tri.uv[0|1|2].u|v|w, tri.worldVertices[0|1|2].x|y|z, ...

Với lại, chỗ cộng edge function mình để (tri.vertices[0].y - tri.vertices[1].y) trong khi trong blog 8 mình rõ ràng nói nó là hằng số cho tam giác hiện tại, mình nên bốc nó ra khỏi vòng lặp luôn.

Như vậy, trước 2 vòng for pixel sẽ có thêm các biến sau:

const edgeSlopeX01 = vertex0.y - vertex1.y;
const edgeSlopeX12 = vertex1.y - vertex2.y;
const edgeSlopeX20 = vertex2.y - vertex0.y;
const edgeSlopeY01 = vertex1.x - vertex0.x;
const edgeSlopeY12 = vertex2.x - vertex1.x;
const edgeSlopeY20 = vertex0.x - vertex2.x;

const perspectiveWorld0X = world0.x * uv0W, perspectiveWorld0Y = world0.y * uv0W, perspectiveWorld0Z = world0.z * uv0W;

const perspectiveWorld2X = world2.x * uv2W, perspectiveWorld2Y = world2.y * uv2W, perspectiveWorld2Z = world2.z * uv2W;

Như thế 2 vòng for sẽ trở thành: 
for (let y = bbox[2]; y <= bbox[3]; y++) {
    let edgeFunction01 = edgeFunctionRow01;
    let edgeFunction12 = edgeFunctionRow12;
    let edgeFunction20 = edgeFunctionRow20;
    let pixelIndex = y * canvasWidth + bbox[0];
    for (let x = bbox[0]; x <= bbox[1]; x++) {
        if (edgeFunction01 > 0 && edgeFunction12 > 0 && edgeFunction20 > 0) {
            const baryCoord0 = edgeFunction12 / signedDoubleArea;
            const baryCoord1 = edgeFunction20 / signedDoubleArea;
            const baryCoord2 = edgeFunction01 / signedDoubleArea;
            const z = vertex0Z * baryCoord0 + vertex1Z * baryCoord1 + vertex2Z * baryCoord2;

            if (z < depthBuffer[pixelIndex]) {
                depthBuffer[pixelIndex] = z;

                const pixelInvZ = uv0W * baryCoord0 + uv1W * baryCoord1 + uv2W * baryCoord2;

                const pixelWorldX = (perspectiveWorld0X * baryCoord0 + perspectiveWorld1X * baryCoord1 + perspectiveWorld2X * baryCoord2) / pixelInvZ;
                const pixelWorldY = (perspectiveWorld0Y * baryCoord0 + perspectiveWorld1Y * baryCoord1 + perspectiveWorld2Y * baryCoord2) / pixelInvZ;
                const pixelWorldZ = (perspectiveWorld0Z * baryCoord0 + perspectiveWorld1Z * baryCoord1 + perspectiveWorld2Z * baryCoord2) / pixelInvZ;

                let shadowFactor = 1.0;
				if (useShadow && dirLight.isInShadow(pixelWorldX, pixelWorldY, pixelWorldZ, worldNormalX, worldNormalY, worldNormalZ)) {
					shadowFactor = 0.5;
				}

				let totalPointLightDiffuse = 0;
				for (let i = 0; i < pointLights.length; i++) {
					const lightPos = pointLights[i].pos;
					const pointLightVecX = lightPos.x - pixelWorldX;
					const pointLightVecY = lightPos.y - pixelWorldY;
					const pointLightVecZ = lightPos.z - pixelWorldZ;
					const distanceFromPixelToPointLight2 =
						pointLightVecX * pointLightVecX + pointLightVecY * pointLightVecY + pointLightVecZ * pointLightVecZ;
					if (distanceFromPixelToPointLight2 >= pointLightRangeSquare) continue;

					const distance = Math.sqrt(distanceFromPixelToPointLight2);
					const dot = (worldNormalX * pointLightVecX + worldNormalY * pointLightVecY + worldNormalZ * pointLightVecZ) / distance;
					const currentPointLightDiffuse = (1 + dot) / 2;
					const pointLightDistanceRatio = distanceFromPixelToPointLight2 / pointLightRangeSquare;
					const inverseSquareDistance = 1 / (1 + 0.02 * distanceFromPixelToPointLight2);
					const attenuation = (1 - pointLightDistanceRatio) * inverseSquareDistance;
					totalPointLightDiffuse += currentPointLightDiffuse * attenuation;
				}
				totalPointLightDiffuse *= pointLightIntensity;

				const lightIntensity = Math.max(ambientLight, (dirLightDiffuse + totalPointLightDiffuse) * shadowFactor);

                let texR = triColor.r, texG = triColor.g, texB = triColor.b;
                if (texturePixels) {
                    const pixelU = (uv0U * baryCoord0 + uv1U * baryCoord1 + uv2U * baryCoord2) / pixelInvZ;
                    const pixelV = (uv0V * baryCoord0 + uv1V * baryCoord1 + uv2V * baryCoord2) / pixelInvZ;
                    const texX = Math.floor(pixelU * (textureWidth - 1));
                    const texY = Math.floor(pixelV * (textureHeight - 1));
                    const texIndex = (texY * textureWidth + texX) * 4;
                    texR = texturePixels[texIndex];
                    texG = texturePixels[texIndex + 1];
                    texB = texturePixels[texIndex + 2];
                }

                const colorIndex = pixelIndex * 4;
                screenBuffer[colorIndex] = Math.min(255, texR * lightIntensity);
                screenBuffer[colorIndex + 1] = Math.min(255, texG * lightIntensity);
                screenBuffer[colorIndex + 2] = Math.min(255, texB * lightIntensity);
            }
        }
        edgeFunction01 += edgeSlopeX01;
        edgeFunction12 += edgeSlopeX12;
        edgeFunction20 += edgeSlopeX20;
        pixelIndex++;
    }
    edgeFunctionRow01 += edgeSlopeY01;
    edgeFunctionRow12 += edgeSlopeY12;
    edgeFunctionRow20 += edgeSlopeY20;
}
