1. Đổi resolution lúc đang chạy

Vì đây là một software rasterizer, mọi pixel đều do CPU tính, nghĩa là số pixel chính là thứ quyết định nó nhanh hay chậm. Cho người đọc tự kéo độ resolution xuống hay lên là cách tốt nhất để họ thấy điều đó.

Từ blog 1 tới giờ cái canvas luôn luôn là 400x300, kích thước được viết thẳng trong thẻ <canvas> và Rasterizer cấp phát buffer đúng một lần trong constructor.

Ta thêm 2 input để nhập resolution (mình tăng nó lên 600x450 vì giờ engine đã được optimized): 
<div>
	Canvas resolution:
	<span>
		<input id="canvasResWidth" value="600" size="4" />
		x
		<input id="canvasResHeight" value="450" size="4" />
	</span>
</div>
Reference nó trong code: 
const canvasResWidthInput = (document.getElementById("canvasResWidth"));
const canvasResHeightInput = (document.getElementById("canvasResHeight"));
let canvasRenderWidth = 600;
let canvasRenderHeight = 450;

canvasResWidthInput.value = canvasRenderWidth.toString();
canvasResHeightInput.value = canvasRenderHeight.toString();

...

canvasResWidthInput.addEventListener("change", readAndApplyResolutionInput);
canvasResHeightInput.addEventListener("change", readAndApplyResolutionInput);
Khi 2 input đó thay đổi, hàm readAndApplyResolutionInput được gọi, nó sẽ như sau: 
function readAndApplyResolutionInput() {
	canvasRenderWidth = readResolution(canvasResWidthInput, 16, 1920, canvasRenderWidth);
	canvasRenderHeight = readResolution(canvasResHeightInput, 16, 1440, canvasRenderHeight);
	canvasResWidthInput.value = canvasRenderWidth.toString();
	canvasResHeightInput.value = canvasRenderHeight.toString();
	
	gameCanvas.width = canvasRenderWidth;
	gameCanvas.height = canvasRenderHeight;

	projectionMatrix = Mat4x4.Projection(fov, gameCanvas.height, gameCanvas.width, znear, zfar);
	rasterizer.updateResolution(gameCanvas.width, gameCanvas.height);
}
Hàm readResolution sẽ đọc từ input và check NaN và min max: 
function readResolution(input, min, max, current) {
	let value = parseInt(input.value);
	if (isNaN(value)) return current;
	return Math.max(min, Math.min(max, value));
}
Còn hàm updateRenderResolution là hàm thật sự thay đổi resolution render cho engine, đây là những thứ cần phải làm:
  1. Tính lại projection matrix (nó có chứa tỉ lệ h / w, xem lại blog 3)
  2. Trong rasterizer: init lại imageData, screenBuffer, screenBuffer32, depthBuffer
Như vậy nó sẽ như sau: 
function updateRenderResolution() {
	gameCanvas.width = canvasRenderWidth;
	gameCanvas.height = canvasRenderHeight;

	projectionMatrix = Mat4x4.Projection(fov, gameCanvas.height, gameCanvas.width, znear, zfar);
	rasterizer.updateResolution(gameCanvas.width, gameCanvas.height);
}
Hàm Rasterizer.updateResolution: 
updateResolution(canvasWidth, canvasHeight) {
	this.canvasWidth = canvasWidth;
	this.canvasHeight = canvasHeight;

	this.imageData = this.ctx.createImageData(this.canvasWidth, this.canvasHeight);
	this.screenBuffer = this.imageData.data;
	this.screenBuffer32 = new Uint32Array(this.imageData.data.buffer);
	this.depthBuffer = new Float64Array(this.canvasWidth * this.canvasHeight);
	
	this.clearScreen();
}
