Tái cấu trúc thành engine

Engine cơ bản đã xong, nó làm lại được hết tất cả những gì mà demo cuối htmlPreview53 làm, thậm chí còn có thêm cả point light shadow 😳 Tuy nhiên bây giờ code khá là hỗn độn, biến global quá nhiều, localtion của attribute, uniform để ra 1 tràng rất khó nhìn. Nhiệm vụ của blog này chính là tái cấu trúc lại mọi thứ, làm nó giống như 1 engine có thể xài lại nhiều lần cho các project khác nhau.

Not the cleanest code in the world. Phần này mình sẽ gom mấy cái uniform lại cho từng program một, còn attribute mình để sau.

Đầu tiên, bạn có biết là thật ra mình có thể extract uniform ra từ program không 😳 từ việc extract đó mình có thể tạo các biến chứa địa chỉ các uniform trong 1 vòng for mà không cần phải ghi từng dòng như trên. Ta sẽ làm điều đó thông qua 2 hàm gl.getProgramParameter và gl.getActiveUniform.

Hàm gl.getProgramParameter(program, tên info) để lấy 1 thông tin trong program ra ngoài, thông tin mà chúng ta quan tâm là số uniform trong program, là gl.ACTIVE_UNIFORMS.
Thật ra ta đã sử dụng qua hàm này rồi, sau khi ta tạo program ta dùng hàm này để check lỗi: 
if (!gl.getProgramParameter(program, gl.LINK_STATUS)) {      // gl.LINK_STATUS chính là 1 info có thể lấy
    throw new Error("Program link error: " + gl.getProgramInfoLog(program));
}
Còn hàm gl.getActiveUniform(program, index của uniform) có công dụng lấy thông tin 1 uniform bằng index (địa chỉ) của nó, thông tin của 1 uniform là: name, type (gl.FLOAT, ...) và size (số phần tử nếu là mảng, nếu không phải mảng thì nó = 1). Đối với mảng thì có 1 điều cần lưu ý, ví dụ với uPointShadowMaps, thì nó sẽ trả về name là "uPointShadowMaps[0]" chứ không phải "uPointShadowMaps".
Có số lượng uniform và có cách lấy uniform theo index rồi, tức là ta có thể for qua chúng được 😳

Để gom các thứ cho từng program một, mình tạo một class mới ShaderProgram, class này sẽ là một wrapper cho program của WebGL, bao gồm các hàm liên quan như compileShader, useProgram và các hàm truyền dữ liệu vào uniform.

Đầu tiên là constructor, hàm compileShader và hàm use: 
class ShaderProgram {
    constructor(gl, vertexSource, fragmentSource) { // nhận vào gl context và string của 2 shader
        this.gl = gl;
        // tạo, attach shader, link program y hệt như trước
        this.glProgram = gl.createProgram();
        gl.attachShader(this.glProgram, ShaderProgram.compileShader(gl, gl.VERTEX_SHADER, vertexSource));
        gl.attachShader(this.glProgram, ShaderProgram.compileShader(gl, gl.FRAGMENT_SHADER, fragmentSource));
        gl.linkProgram(this.glProgram);
        if (!gl.getProgramParameter(this.glProgram, gl.LINK_STATUS)) {
            throw new Error("Program link error: " + gl.getProgramInfoLog(this.glProgram));
        }

        // tạo 1 "dictionary" chứa các uniform, không dùng mảng vì ta index bằng tên
        this.uniforms = {};
        const uniformCount = gl.getProgramParameter(this.glProgram, gl.ACTIVE_UNIFORMS);
        for (let i = 0; i < uniformCount; i++) {
            const info = gl.getActiveUniform(this.glProgram, i);    // lấy thông tin uniform theo index
            const name = info.name.replace("[0]", "");              // điều lưu ý đối với mảng mà mình nói ở trên, bỏ "[0]" ra cho đúng tên
            // mỗi phần tử trong "dictionary" này chứa location (để dùng trong các hàm truyền dữ liệu vào uniform), type và size
            this.uniforms[name] = {
                location: gl.getUniformLocation(this.glProgram, info.name),
                type: info.type,
                size: info.size,
            };
        }
    }

    // y hệt như cũ
    static compileShader(gl, type, source) {
        const shader = gl.createShader(type);
        gl.shaderSource(shader, source);
        gl.compileShader(shader);
        if (!gl.getShaderParameter(shader, gl.COMPILE_STATUS)) {
            const log = gl.getShaderInfoLog(shader);
            gl.deleteShader(shader);
            throw new Error("Shader compile error: " + log);
        }
        return shader;
    }

    use() {
        this.gl.useProgram(this.glProgram);
    }
}

Có được bảng trên rồi, thì hàm truyền dữ liệu vào các uniform chỉ cần switch case để dùng hàm cho đúng: 
class ShaderProgram {
    ...
    // nhớ là trước khi gọi hàm này ta phải gọi hàm use trước
    set(name, value) {
        const uniform = this.uniforms[name];        // lấy uniform bằng name
        if (!uniform) throw new Error(`ShaderProgram.set: ${name} is not an active uniform`);

        const gl = this.gl;
        const location = uniform.location;
        switch (uniform.type) {
            case gl.FLOAT:
                if (uniform.size > 1) gl.uniform1fv(location, value);
                else gl.uniform1f(location, value);
                break;
            case gl.FLOAT_VEC3:
                if (uniform.size > 1) gl.uniform3fv(location, value);
                else if (value instanceof Color) gl.uniform3f(location, value.r / 255, value.g / 255, value.b / 255);       // vec3 có thể là màu
                else gl.uniform3f(location, value.x, value.y, value.z);
                break;
            case gl.FLOAT_MAT4:
                gl.uniformMatrix4fv(location, false, value.toColumnMajor());
                break;
            case gl.INT:
            case gl.BOOL:
            case gl.SAMPLER_2D:
            case gl.SAMPLER_CUBE:
                if (uniform.size > 1) gl.uniform1iv(location, value);
                else gl.uniform1i(location, Number(value));
                break;
            default:
                throw new Error(`ShaderProgram.set: type 0x${uniform.type.toString(16)} of ${name} is not supported`);
        }
    }
}

2. VertexLayout, VertexBuffer, VertexArray

Tiếp theo là mình sẽ xử lí mấy cái attribute, và cũng như gom lại hết vertex buffer (VBO) và vertex array (VAO).

Từ đầu tới giờ ta chỉ xài 3 attribute là aPosition, aUV và aNormal, và chúng đã đủ cho những thứ cho ta cần làm: aPosition cho tọa độ đỉnh, aUV cho texture, và aNormal cho lighting. Tuy nhiên trong các engine thật, thì attribute hay đi theo bộ, 1 shader có thể dùng bộ attribute này, trong khi shader khác có thể dùng bộ attribute khác. 1 ví dụ điển hình là trick shadow map debug ở blog trước, thay vì dùng trick gl_VertexID, thì ta có thể pass vào 1 aPosition, đó cũng là 1 bộ attribute, chỉ gồm 1 attribute. Các bộ attribute này gọi là Vertex layout.

Cho nên ta cũng sẽ tạo 1 class VertexLayout để gom lại các attribute, và đồng thời tính stride của chúng để pass vào hàm gl.vertexAttribPointer. Một attribute sẽ bao gồm: name, localtion, size (số component) và offset. Vì nó khá đơn giản nên ta không cần 1 class riêng cho attribute, mà ghi thẳng thành các object trong class VertexLayout.

Class VertexLayout sẽ như sau: 
class VertexLayout {
    constructor(attributes) {
        this.attributes = [];
        let offset = 0;
        for (const attribute of attributes) {
            // attribute truyền vào chỉ có name, location và size. Ta tự thêm vào offset vì cái này VertexLayout mới tính được
            this.attributes.push({ ...attribute, offset: offset });
            offset += attribute.size * 4;       // 3 attribute của ta đều chứa toàn float, mỗi float 4 byte
        }
        this.stride = offset;       // sau vòng for trên thì offset bằng tổng size các attribute, chính là stride
    }

    // bộ attribute mà ta xài ở toàn engine, để luôn thành 1 static
    static standard = new VertexLayout([
        { name: "aPosition", location: 0, size: 3 },
        { name: "aUV", location: 1, size: 2 },
        { name: "aNormal", location: 2, size: 3 },
    ]);
}
Trong 2 vertex shader, ta có set layout(location = 0) cho aPosition để xác nhận index của aPosition luôn là 0 ở mọi program, làm như vậy để biến aPosition dùng được cho cả program chính và shadow program. Chữ layout đó chính là VertexLayout 😳, như vậy bây giờ ta hiểu full nghĩa của đoạn đó là "trong 1 vertex layout, index của aPosition là 0". Như vậy, để cho chắc ăn thì ta sẽ set luôn location cho aUV và aNormal trong vertex shader chính:

Tiếp theo là gom VBO và VAO thành class VertexBuffer và VertexArray. Constructor của VertexBuffer sẽ nhận vào dữ liệu (1 Float32Array) cho buffer, tạo buffer, bind và truyền dữ liệu vào buffer đó, ngoài ra còn lưu thêm byteLength của Float32Array để tiện dùng khi cần: 
class VertexBuffer {
    constructor(gl, data) {
        this.gl = gl;
        this.glBuffer = gl.createBuffer();
        gl.bindBuffer(gl.ARRAY_BUFFER, this.glBuffer);
        gl.bufferData(gl.ARRAY_BUFFER, data, gl.STATIC_DRAW);
        this.byteLength = data.byteLength;
    }
}
Class VertexBuffer chỉ có nhiêu đó 😳 nó chỉ là để wrap buffer của WebGL lại rồi cho bên ngoài xài dữ liệu của nó. Thật ra nếu đầy đủ thì phải có thêm hàm bind để bind lại buffer này khi cần, nhưng engine chúng ta thì bind mọi dữ liệu 1 lần duy nhất ngay lúc bắt đầu, nên cũng không cần.

Tiếp theo là class VertexArray. Nếu bạn không nhớ rõ VAO làm gì, thì nó đơn giản chỉ là nhớ attribute nào đọc phần nào của 1 buffer, ngoài ra nó còn nhớ element buffer để hàm drawElements biết lấy đỉnh nào theo thứ tự nào để vẽ, nhưng ta bỏ element buffer từ lâu rồi nên không cần quan tâm. Như vậy constructor của VertexArray sẽ nhận vào 1 VertexLayout và 1 VertexBuffer, nó sẽ tạo VAO, gọi hàm vertexAttribPointer để "nối" các attribute và buffer dựa vào stride và offset của chúng. Ngoài ra mình thêm hàm vertexCount (tính số đỉnh bằng kích thước byte của vertex buffer chia cho stride), và draw (bind VAO xong vẽ thôi): 
class VertexArray {
    constructor(gl, layout, vertexBuffer) {
        this.gl = gl;
        this.layout = layout;
        this.vertexBuffer = vertexBuffer;

        this.glVertexArray = gl.createVertexArray();
        gl.bindVertexArray(this.glVertexArray);
        gl.bindBuffer(gl.ARRAY_BUFFER, vertexBuffer.glBuffer);
        for (const attribute of layout.attributes) {
            gl.enableVertexAttribArray(attribute.location);
            gl.vertexAttribPointer(attribute.location, attribute.size, gl.FLOAT, false, layout.stride, attribute.offset);
        }
        gl.bindVertexArray(null);
    }

    get vertexCount() {
        return this.vertexBuffer.byteLength / this.layout.stride;
    }

    draw() {
        const gl = this.gl;
        gl.bindVertexArray(this.glVertexArray);
        gl.drawArrays(gl.TRIANGLES, 0, this.vertexCount);
    }
}

3. Index buffer và Mesh

Đúng vậy, tiêu đề không sai, chúng ta sẽ mang index buffer trở lại 😳 Blog 3 mình có nói là không xài index buffer được vì các đỉnh có tọa độ giống nhau không có nghĩa là có pháp tuyến giống nhau (3 tam giác chung 1 đỉnh trong 1 cube). Tuy nhiên, "không có nghĩa" không có nghĩa là "tất cả", ví dụ như các tam giác nằm chung 1 mặt phẳng, thì các đỉnh trùng nhau của chúng là có chung pháp tuyến luôn.

Như vậy ta sẽ tạo 1 class IndexBuffer, constructor nhận vào các index, nó sẽ lưu lại số lượng index, loại của index (int32 hay int16, mình có nói ở blog 1). Sau đó nó tạo 1 buffer để lưu các index đó vào khe gl.ELEMENT_ARRAY_BUFFER, tuy nhiên trước khi bind khe để lưu thì nên bỏ bind VAO trước, vì bạn nhớ là VAO cũng nhớ luôn element buffer giùm mình, mình mà còn bind VAO thì lúc truyền vào element buffer, nó sẽ thay đổi luôn VAO đó. Như vậy class sẽ như sau (chỉ có constructor); 
class IndexBuffer {
    constructor(gl, indices) {
        this.gl = gl;
        this.count = indices.length;
        this.type = indices instanceof Uint32Array ? gl.UNSIGNED_INT : gl.UNSIGNED_SHORT;       // check kiểu của index để lưu cho đúng
        this.glBuffer = gl.createBuffer();
        gl.bindVertexArray(null);           // ELEMENT_ARRAY_BUFFER là một phần của VAO, đừng ghi đè index buffer của VAO đang bind
        gl.bindBuffer(gl.ELEMENT_ARRAY_BUFFER, this.glBuffer);
        gl.bufferData(gl.ELEMENT_ARRAY_BUFFER, indices, gl.STATIC_DRAW);
    }
}
Vì VAO chứa index buffer, nên ta phải thêm nó vào trong class VertexArray:

Trước khi nói về class Mesh, mình sẽ nói về class Triangle trước: 
class Triangle {
    constructor(vertices = [], uv = [], color = new Color(255, 255, 255)) {
        this.vertices = vertices;
        this.uv = uv;
        this.color = color;
        this.normal = Vector3.forward.clone();

        this.updateNormal();
    }

    updateNormal() {
        let edge1 = Vector3.sub(this.vertices[0], this.vertices[1]);
        let edge2 = Vector3.sub(this.vertices[1], this.vertices[2]);
        this.normal = Vector3.cross(edge1, edge2).normalize();
    }
}
Cơ bản bây giờ là nó chỉ là 1 cục dữ liệu chứ không còn làm gì nữa, việc xử lí dữ liệu các thứ đã nằm hết ở shader, ở Javascript ta chỉ cần xếp data cho đúng rồi truyền hết vào cho GPU là xong. Cho nên mình quyết định bỏ class Triangle và nhét những dữ liệu của nó vào Mesh luôn 😳 Tức là bây giờ Mesh không còn chứa danh sách tam giác, mà chứa luôn full danh sách đỉnh, uv, normal, và cả index. Màu thì không chứa nữa do thực tế ta cũng ko dùng: 
class Mesh {
    constructor(positions, uvs, normals, indices) {
        this.positions = positions;
        this.uvs = uvs;
        this.normals = normals;
        this.indices = indices;
        this.uploadToGPU();
    }

    get vertexCount() {
        return this.positions.length / 3;
    }
}
