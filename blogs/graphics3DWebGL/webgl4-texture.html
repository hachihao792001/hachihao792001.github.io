Texture

Thêm texture vào WebGL thật ra khá dễ, quan trọng là cách mình cấu trúc code, bind state, vẽ khi nào thôi.

Đây là class Texture ở Software Rasterizer của chúng ta: 
class Texture {
	constructor(url = "") {
		this.pixels = null;
		this.width = 0;
		this.height = 0;
		if (url) this.load(url);
	}

	async load(url) {
		const img = new Image();
		img.crossOrigin = "anonymous";
		img.src = url;
		const loaded = new Promise((resolve) => {
			img.onload = () => {
				resolve();
			};
		});
		await loaded;
		const tempCanvas = document.createElement("canvas");
		tempCanvas.width = img.width;
		tempCanvas.height = img.height;
		const tempCtx = (tempCanvas.getContext("2d"));
		tempCtx.drawImage(img, 0, 0);
		this.pixels = tempCtx.getImageData(0, 0, img.width, img.height).data;
		this.width = img.width;
		this.height = img.height;
	}
}
Ta sẽ không xóa code nào trong class này hết, mà tiếp tục thêm vào nó, vì class này đúng là chỉ làm việc liên quan tới texture và các pixel của nó, chứ không liên quan gì engine.

Đầu tiên là ta truyền dữ liệu Texture cho WebGL, cụ thể, trong constructor ta tạo 1 texture mới trong GPU bằng hàm gl.createTexture: 
constructor(url = "", gl = null) {		// truyền gl vào để Texture xài
	this.pixels = null;
	this.width = 0;
	this.height = 0;
	this.gl = gl;							// <-----------------------
	this.glTexture = gl.createTexture();	// <-----------------------
	if (url) this.load(url);
}
Trong hàm load ta sẽ truyền dữ liệu vào texture đó: 
async load(url) {
	...

	this.gl.bindTexture(gl.TEXTURE_2D, this.glTexture);
	this.gl.texImage2D(gl.TEXTURE_2D, 0, gl.RGBA, this.width, this.height, 0, gl.RGBA, gl.UNSIGNED_BYTE, new Uint8Array(this.pixels.buffer));

	this.gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MIN_FILTER, gl.NEAREST);
	this.gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_MAG_FILTER, gl.NEAREST);
	this.gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_S, gl.CLAMP_TO_EDGE);
	this.gl.texParameteri(gl.TEXTURE_2D, gl.TEXTURE_WRAP_T, gl.CLAMP_TO_EDGE);
}
Hàm gl.bindTexture thì nhìn quá quen thuộc r, còn gl.TEXTURE_2D chính là một "khe" mới mà ta chưa biết. Còn hàm gl.texImage2D có tham số như sau: 
gl.texImage2D(
	// khe,
	// mipmap level, nếu bạn chơi game nhiều bạn sẽ biết thuật ngữ này, mipmap là việc lưu các version nhỏ hơn của 1 texture để tối ưu
	// internal format, là format mà webgl lưu,
	// width,
	// height,
	// có border hay không,
	// format truyền vào,
	// kiểu của buffer,
	// các pixel kiểu Uint8Array, vì pixels của Texture là kiểu Uint8ClampedArray (kiểu từ getImageData trả về) nên phải convert)
Tiếp theo là 4 dòng gl.texParameteri, hàm gl.texParameteri(khe, parameter, value) set các parameter cho texture hiện tại đang được bind, cụ thể:
  • gl.TEXTURE_MIN_FILTER: Cách xử lí khi texture được render nhỏ hơn texture gốc. gl.NEAREST nghĩa là lấy pixel gần nhất.
  • gl.TEXTURE_MAG_FILTER: Tương tự như trên nhưng với texture render lớn hơn texture gốc
  • gl.TEXTURE_WRAP_S: Cách xử lí khi lấy 1 pixel có u (tọa độ ngang) bên ngoài khoảng [0; 1]. gl.CLAMP_TO_EDGE nghĩa là lấy màu y hệt cạnh của texture gốc.
  • gl.TEXTURE_WRAP_T: Tương tự như trên nhưng với v (tọa độ dọc).
Ngoài ra còn nhiều cách xử lí các trường hợp trên, bạn có thể xem doc của Unity về vấn đề này, trong trỏng có 2 hình dưới đây nhìn khá dễ hiểu:

2. Đưa UV lên GPU

Đã đụng tới texture thì phải đụng tới UV, cho nên ta phải truyền thêm UV vào vertex shader. Ta cũng làm tương ứng như trước: thêm uv vào vertex data, thêm attribute mới trong vertex shader, và truyền vào đúng stride, offset. Tọa độ là 3 float, giờ thêm 2 float của uv nữa thì mỗi vertex có 5 float. 5 float là 20 byte, nên aPosition có stride 20 byte và offset 0; attribute mới aUV cũng có stride 20 byte nhưng offset 12 byte (sau 3 float tọa độ): 
class Mesh {
	...

	uploadToGPU() {
		const vertexData = new Float32Array(this.tris.length * 15);	// 1 tam giác = 3 vertex * 5 float
		for (let i = 0; i < this.tris.length; i++) {
			for (let j = 0; j < 3; j++) {
				const vertex = this.tris[i].vertices[j];
				vertexData[i * 15 + j * 5] = vertex.x;
				vertexData[i * 15 + j * 5 + 1] = vertex.y;
				vertexData[i * 15 + j * 5 + 2] = vertex.z;
				vertexData[i * 15 + j * 5 + 3] = this.tris[i].uv[j].u;		// <---------------
				vertexData[i * 15 + j * 5 + 4] = this.tris[i].uv[j].v;		// <---------------
			}
		}
		...

		gl.enableVertexAttribArray(aPosition);
		gl.vertexAttribPointer(aPosition, 3, gl.FLOAT, false, 20, 0);		// <---------------
		gl.enableVertexAttribArray(aUV);									// <---------------
		gl.vertexAttribPointer(aUV, 2, gl.FLOAT, false, 20, 12);			// <---------------
		...
	}
}
Trong vertex shader, UV được nhận qua attribute rồi chuyển tiếp cho fragment shader: 
...
in vec2 aUV;		// <---------------
out vec2 vUV;		// <---------------

void main() {
	gl_Position = uProjection * uView * uModel * vec4(aPosition, 1.0);
	vUV = aUV;		// <---------------
}
...
in vec2 vUV;
out vec4 outColor;

void main(){
	// sử dụng vUV thế nào phần dưới sẽ nói
	outColor = vec4(color, 1.0);
}

3. Lấy màu texture trong fragment shader

Fragment shader nhận vUV từ vertex shader, là UV đã được nội suy (và perspective correct) cho pixel hiện tại, việc của ta hiện tại chỉ là lấy đúng pixel trong Texture ra để hiển thị. Để làm được điều đó, ta khai báo một uniform sampler2D để nhận texture, rồi gọi hàm texture để lấy màu tại vUV: 
uniform sampler2D uTexture;		// <---------------
uniform bool uUseTexture;		// <---------------
uniform vec3 uColor;
in vec2 vUV;
out vec4 outColor;

void main() {
	vec3 color = uUseTexture ? texture(uTexture, vUV).rgb : uColor;		// <---------------
	outColor = vec4(color, 1.0);
}
uTexture là sampler trỏ tới texture unit. Còn uUseTexture để bật tắt texture, dành cho trường hợp GameObject không có texture, hoặc chưa load được texture. Nếu uUseTexture false thì fragment shader dùng uColor như trước.
