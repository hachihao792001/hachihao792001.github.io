World Tour (opens in a new tab)

University Unity, C#, React, Java Spring, PostgreSQL, Azure Kinect DK, HoloLens 2

Another project that I built for my bachelor thesis, it harnesses the combined capabilities of Microsoft Azure Kinect DK and Microsoft HoloLens 2, offering a fully immersive Extended Reality (XR) environment.Within this environment, users employ the HoloLens 2 to interact with a globe, selecting destinations to explore and utilizing body gestures for navigation within the chosen destination. Much like the HCMUS Tour project, this application integrates a web server and an administrator web interface to serve identical purposes.
