HCMUS Tour (opens in a new tab)

University Unity, C#, React, Java Spring, PostgreSQL, Azure Kinect DK

One of the projects I built for my bachelor thesis, it involves utilizing the Microsoft Azure Kinect DK to facilitate user navigation and exploration of Ho Chi Minh City University of Science using the user's body gestures. This system seamlessly communicates with a web server to acquire essential information and assets. Additionally, an administrator web interface is integrated, allowing for the modification of pertinent information.
